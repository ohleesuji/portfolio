# 이수지 Product Portfolio

Public website: https://ohleesuji.github.io/portfolio/

A static, responsive portfolio with 25 project cases, career history, selected outcomes, enlarged evidence images, and a downloadable career deck.

- `index.html`: overview, selected outcomes, working approach
- `data.js`: company history and project content
- `app.js`: company navigation and image viewer
- `style.css`: desktop and mobile layouts
- `assets/`: portfolio evidence and career deck

Career figures use actual employed dates, including both endpoints, as of September 21, 2026. The overlap between NHN DATA and Toss (March 29–31, 2021) is counted once. Total: 4,281 days; the headline shows completed years and months using 365 days/year and 30 days/month (11 years 8 months). Individual company durations use calendar year/month/day differences.

Local preview: `python3 -m http.server 8765`

Deployment: GitHub Pages from the root of `main`. No build step required.
